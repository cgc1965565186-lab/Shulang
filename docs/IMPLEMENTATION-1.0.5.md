# 1.0.5 开发记录

此记录描述 1.0.5 源码及其验证情况，发行签名和公证链仍待完成。

## 当前实现

- 清理使用写前日志，逐项复核路径、身份及修改信息；中断记录可重启后核查，恢复按项报告冲突与失败。旧版缺少成功证据的历史不会被推断为可恢复。
- 疑似残留须人工核对，目录内容变化或无法完整读取时拒绝执行；重复项哈希后进行流式字节比较，复核保留项，禁止选中保留文件或其父目录。
- 启动时检测已有进程并对历史目录加锁，避免多个新版实例同时写入恢复记录；旧版本之间仍不具备该保护。
- 扫描包含本地隐藏目录，报告单独记录排除、截断和无法访问的范围；取消结果标为只读。版本化元数据快照保存在 SQLite WAL，FSEvents 标记变化目录；无法确认可靠覆盖时回退完整扫描。
- 命令行可导出扫描快照并比较覆盖范围和设置相同的快照。界面后台筛选与排序候选，文件列表分页，空间图使用只读快照在后台计算并缓存。
- 应用清单支持标准及用户添加的位置，但目前只读，完整卸载尚未接入。

## 验证边界

- 2026-11-08 在获得沙箱外运行许可后，68 项 Swift 测试全部通过，包括真实 FSEvents 和系统废纸篓往返测试；文件操作使用专门生成的夹具。此前沙箱内运行时这三项集成测试被跳过。
- 2026-11-08 universal2 release 本地构建和 ad-hoc 签名校验通过；两次启动后只保留一个进程。此前沙箱内构建被 `dsymutil` 权限限制阻断。
- 安装版本采用 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证。
- 图形界面已检查启动、隔离目录扫描、重复项发现及两种空间图；测试目录经系统文件选择器转换为 `/tmp` 后因符号链接祖先被清理保护拒绝，未完成图形界面删除与恢复操作。
- 尚未完成完整用户界面与无障碍实测、百万节点 GUI 性能和内存验收；文件删除后空间图仍有同步计算回退。正式 Developer ID 签名、公证、发布来源证明及自动更新未实现。
- 基准使用独立临时目录和指定 CLI；报告中的内存为扫描进程峰值 RSS，不包含 GUI。测试结果必须注明构建类型、规模和运行次数，不能由单次结果推断 P95。
- 2026-11-08，10 万生成文件、调试版 CLI、每种枚举器各 1 次：Foundation 38.9494 秒、峰值 RSS 157,876,224 字节；bulk 17.1440 秒、110,444,544 字节。该次 CLI 未启用隐藏项，结果仅作定位参考。
- 2026-11-08，100 万生成文件、包含隐藏项、调试版 CLI、每种枚举器各 1 次：Foundation 371.0011 秒、峰值 RSS 838,352,896 字节；bulk 175.3268 秒、971,456,512 字节。两者扫描到的节点和文件数相同；这是 CLI 进程的单次结果，不能证明 GUI P95 或正式构建性能。
