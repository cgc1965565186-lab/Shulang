# 威胁模型

| 威胁 | 触发条件 | 现有缓解 | 验证 |
|---|---|---|---|
| 非预期删除用户文件 | 规则过宽、误选 | 默认零勾选、三级风险、逐项证据、二次确认 | dry-run 与 PathGuard 单测 |
| 路径逃逸 / 符号链接替换 | 删除前路径被替换 | 祖先链符号链接检查、身份复核、每 50 项重校验 | 单测与 fixture |
| 越权删除系统文件 | 构造恶意 DeletePlan | 引擎层拒绝清单（不依赖 UI） | testDeletePlanRejectsProtectedPaths |
| 批量枚举器读到错误元数据 | 文件系统不支持、缺字段 | 返回 nil 回落 Foundation，绝不猜测 | 回落单测、benchmark 对照 |
| 社区规则包投毒 | 导入含危险模式 | Schema 校验、不安全字符拦截、纯数据约束 | testRuleSetImportRejectsInvalidInput |
| 供应链 / 签名密钥泄露 | PR 触发签名流程 | 本版本仅本地 ad-hoc；官方发布要求受控 runner | 发布流程文档 |
| 隐私泄露 | 日志或报告含敏感路径 | 全部本地生成、零网络、无遥测、无账号 | 报告导出测试 |
| 永久数据丢失 | 清空废纸篓 | 只移入废纸篓、提供恢复入口、UI 与报告明确说明 | golden deletion |
| 拒绝服务（超大目录） | 条目过多或路径过深 | 深度上限 64、单目录 200,000 条上限、跳过并记录 | 扫描错误报告 |
| TCC 越权 | 诱导关闭系统安全 | 不调用 tccutil、不读写 TCC 数据库、不引导关闭 SIP/Gatekeeper | 代码审计 |

源码公开意味着缓解逻辑本身可被审阅，安全测试应包含「已知源码前提下的绕过尝试」。
