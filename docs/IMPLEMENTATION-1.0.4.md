# 1.0.4 实施记录

本版本侧重修复基础问题，不代表 1.1 / 1.2 或正式发布计划已完成。无 Developer ID 公证。

## 已实施

- 清理逐项写前记录，移动后保存成功项目；重启按文件身份定位中断项目。无法定位时保留待核查状态，阻止继续删除。
- 损坏历史禁止覆盖；旧版只有计划的记录不推断成功。
- 执行前检查扫描身份、大小、修改时间；重复副本验证保留文件身份、完整哈希及流式内容比较。
- 疑似残留加入清单默认不勾选；执行前复核宿主。应用清单遍历嵌套目录，覆盖系统 Cryptex 应用。
- 导入规则不能自行获取内置信任；批量选择排除谨慎项及未验证规则。
- 隐藏目录和应用包参与统计；包内文件不产生规则清理建议。
- 候选筛选、排序和扫描差异计算移至后台，过期搜索结果不发布；恢复在后台执行并触发重扫。
- 清理确认冻结计划；清理异常更新已经记入日志的成功项目。
- 移除列表静默截断及残留概率说明，隐藏尚未接通的自动化导航。
- 应用、CLI、SBOM 采用同一应用版本来源。

## 验证

- 当前单元与隔离文件系统测试：37 项通过（含显式启用的真实废纸篓测试）。
- 隔离夹具包含普通文件、隐藏目录、应用包及缓存：Foundation / bulk 均统计 4 个文件、15,360 字节逻辑大小。
- 真实系统废纸篓：专门生成的文件成功移入、从磁盘重新加载事务后恢复，内容一致。崩溃窗口注入测试使用替代废纸篓目录。
- 图形界面：隔离目录扫描、默认零勾选、选择可重建项、复核及只读预演通过。
- 10 万文件单次基准：Foundation 31.855 秒，bulk 12.9222 秒；含进程启动，不能解释为 P95 或普遍性能结论。

## 未完成与限制

- 原子日志写入不等同于断电持久性保证；未定位的事务不能自动推断成功。
- 完整只读扫描快照、取消后部分结果、有界并发、节点索引及布局缓存尚未完成。
- 百万节点、主线程 P95 与峰值内存目标未验收。外置卷崩溃恢复未验收，无法定位时要求手动核查。
- 疑似残留检测不能证明宿主不存在，无法完整识别自定义目录、共享组件；尚非完整卸载器。
- SQLite / FSEvents 增量扫描、完整应用卸载、重复检测取消和独立进度待补齐。
- 设置与规则持久化、界面可访问性全流程验收和正式签名发布链待完成。

## 继续开发中的源码变更（尚未安装）

- 扫描报告添加完成状态、排除与截断路径、隐藏项设置和枚举器回退数；取消后保留只读部分树，重扫前禁止从中清理。
- 图形界面区分取消、权限不足、策略排除和截断；旧格式报告保持可读。
- 节点索引减少逐项查找；矩形图排序布局、文件列表排序和报告导出移至后台；文件列表分批加载，旭日图与文件列表使用所选大小口径。
- 重复检测增加取消和阶段进度，完整哈希之后再流式比较内容。
- 保存扫描设置和规则开关；导入规则重启时重新按未验证来源解析。
- 仅在设备与 inode 身份一对一对应时报告重命名；专用缓存规则先于通用缓存规则。

隔离预览构建已通过 ad-hoc 签名校验和基础 CLI 夹具检查；文件列表分批加载是在该预览构建之后加入，尚未打包。当前源码 45 项测试中 44 项通过、1 项系统废纸篓集成测试默认跳过；图形界面完整验收和安装仍未完成。目录枚举取消可能丢弃当前正在枚举的整个目录，不会将其标成完整扫描；有界并发、渐进快照、布局跨页面缓存、SQLite/FSEvents 增量扫描、完整应用卸载和百万节点验收仍未完成。

CI 已将运行器从不存在的 macos-27 调整为 xcode-27，源码构建校验与本机安装检查分离；尚未在托管环境实际运行。
